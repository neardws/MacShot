# Getting started

## Install

1. Download the latest release from GitHub.
2. Open `Octoshot.app` and allow **Screen Recording** when prompted.
3. Optional: grant **Accessibility** if you use scroll capture with auto-scroll.

## Menu bar

Octoshot lives in the menu bar (no Dock icon by default). Open **Settings…** from the menu or press **⌘,**.

## First-run onboarding

Onboarding walks through permissions, optional system screenshot shortcut takeover, and optional Ollama setup. You can revisit any step in **Settings**.

## Save location

**Settings → Capture** chooses the default folder and image format (PNG/JPEG).

## Help

Press **⌘?** or choose **Help → Octoshot Help** to open this guide inside the app.
