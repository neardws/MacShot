# Octoshot user guide

Octoshot (一酱) is a macOS menu-bar app for screenshots, scroll capture, screen recording, GIF export, annotation, and optional on-device AI.

## What you can do

- **Area, window, and fullscreen** capture with global shortcuts
- **Mode bar** while selecting a region: screenshot, scroll stitch, video, GIF, LaTeX, figure/table helpers
- **Quick Access** thumbnail for copy, save, annotate, and local smart suggestions
- **Settings** sidebar for shortcuts, capture, recording, AI, and developer/agent tools

## Privacy

Capture and embedded models run on your Mac by default. Nothing is uploaded unless you configure an external service (for example Ollama).
