# Shortcuts

## Global hotkeys

Configure area, window, and fullscreen capture in **Settings → Shortcuts**.

## System screenshots

Octoshot can read macOS screenshot shortcuts (⌘⇧3/4/5) and optionally **take over** those bindings. The settings pane links to Keyboard settings to disable Apple's defaults.

## Mode bar (during area selection)

| Key | Action |
| --- | --- |
| S | Screenshot |
| R | Scroll stitch |
| V | Region video |
| G | Region GIF |
| L | LaTeX |
| T | Figure/table |
