# 快速开始

## 安装

1. 从 GitHub 下载最新发行版。
2. 打开 `Octoshot.app`，按提示允许 **屏幕录制**。
3. 若使用自动滚动拼接，可选授予 **辅助功能**。

## 菜单栏

章鱼君常驻菜单栏（默认无 Dock 图标）。在菜单中选择 **Settings…** 或按 **⌘,**。

## 首次引导

引导流程会说明权限、可选的系统截图快捷键接管，以及可选的 Ollama。可在 **设置** 中随时调整。

## 保存位置

在 **设置 → Capture** 中设置默认文件夹与图片格式（PNG/JPEG）。

## 帮助

按 **⌘?** 或 **Help → Octoshot Help** 在应用内打开本指南。
