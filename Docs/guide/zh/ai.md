# 本机 AI

## 嵌入式模型

可选下载至 `~/Library/Application Support/Octoshot/Models/`：

- **SmolVLM2**（MLX）用于视觉相关任务
- **pix2tex** 用于公式转 LaTeX

在 **设置 → AI** 中下载、查看进度与磁盘占用。

## Ollama（可选）

Ollama 为 OpenAI 兼容的本机 API 回退；安装嵌入式模型后默认保持关闭 Ollama。

## LaTeX 捕获

区域模式条按 **L**，或菜单 **Capture Formula (LaTeX)…**；结果在专用窗口中复制。

## 智能建议

快速访问可能显示 **top-1** 本机建议，点击 **Apply** 执行。分类在本机完成。

构建与许可说明见仓库 `Docs/EMBEDDED_AI.md`。
