# 录制与 GIF

## 全屏录制

菜单栏中：

- **Record Fullscreen (Video)** — ScreenCaptureKit 输出 H.264 MP4
- **Record Fullscreen (GIF)** — 定时帧导出 GIF

录制时显示浮动 **停止** 面板与菜单栏指示。

## 区域视频 / GIF

**Capture Area** 后在模式条按 **V**（视频）或 **G**（GIF）。

## 设置

**设置 → Recording** 可调整光标显示、GIF 帧率与最大宽度、滚动捕获选项。

## 权限

所有捕获与录制功能均需 **屏幕录制** 权限。
