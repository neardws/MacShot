# 一酱使用指南

一酱（Octoshot）是 macOS 菜单栏截图与录屏工具，支持滚动拼接、标注，以及可选的本机 AI。

## 主要能力

- **区域 / 窗口 / 全屏**截图与全局快捷键
- 区域选择时的 **模式条**：截图、滚动拼接、视频、GIF、LaTeX、图/表助手
- **快速访问**缩略图：复制、保存、标注与本机智能建议
- **设置**侧栏：快捷键、捕获、录制、AI、开发者/Agent

## 隐私

默认在本机处理；除非你配置外部服务（如 Ollama），不会上传截图。

## 更多章节

请使用侧栏打开 **快速开始**、**捕获模式**、**录制与 GIF**、**本机 AI**、**Agent 与 CLI**、**快捷键**。
