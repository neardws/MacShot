# Octoshot v0.3.2

## 中文

- 修复：在全屏应用中无法进行区域截图；快速访问浮窗、贴图等窗口现在也能显示在全屏应用之上，截图时不再抢占前台 (#66)
- 快速访问浮窗：点击叠放即可展开，点外面或「收起」合上；鼠标悬停每张缩略图会出现 ×，可单独从浮窗移除（不删除文件）(#64)
- 修复：右下角叠放折叠方向与尺寸异常；截图被拖出后会自动从浮窗移除 (#59)
- 修复：设置页 General 上方被工具栏遮挡 (#64)
- 中文名改为「一酱」(#63)
- 更新地址改为 https://www.neardws.com/Octoshot/appcast.xml (#61)

> 注意：0.3.0 / 0.3.1 内置的更新地址经过一次 http 跳转，自动更新可能无法检测到本版本。如未收到更新提示，请从 GitHub Release 手动下载安装一次，之后即可正常自动更新。

## English

- Fixed region capture not working over full-screen apps; Quick Access, pinned screenshots and related windows now appear above full-screen Spaces, and capture no longer steals focus (#66)
- Quick Access: click the stack to expand it, click outside or "Collapse" to fold it; hover a thumbnail and click × to dismiss it from the stack (the file is kept) (#64)
- Fixed the collapsed stack layout in the bottom-right corner; screenshots dragged out of Quick Access are removed from the stack (#59)
- Fixed the Settings toolbar covering the top of the General pane (#64)
- Chinese display name is now 一酱 (#63)
- Update feed moved to https://www.neardws.com/Octoshot/appcast.xml (#61)

> Note: 0.3.0 and 0.3.1 use an older feed URL that goes through an http redirect, so they may not detect this update automatically. If you don't see an update prompt, download and install this release manually once from GitHub Releases; future updates will work normally.
